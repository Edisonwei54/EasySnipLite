# EasySnipLite

轻量快速的 Windows 截图与标注工具 —— 按下全局快捷键，拖拽框选区域，标注后复制、保存或贴到屏幕。专注日常截图与无缝长截图。

> 当前进度：M0-M3 已完成（热键唤起 → 冻结屏幕 → 框选 → 8 手柄调整 / 方向键微调 / 放大镜 → **标注编辑器**：8 种工具 + 撤销重做 → 复制 / 保存 / 完成已可用）；滚动长截图已实现但决定跳过（代码存档，托盘入口已移除）；贴屏（M5）已完成，手工 E2E 已验证；设置 + 三语（M6）已完成（单测 176/176，手工 E2E 已验证）；打磨 + 发布（M7）已完成（错误处理管线 / 启动与保存失败气泡 / 单测 188/188，verify-m7 发布冒烟验证通过，版本 1.0.0）。详见 [docs/PROGRESS.md](docs/PROGRESS.md)。

## 🚀 快速开始

```bash
# 构建
dotnet build EasySnipLite.slnx

# 运行（Debug 构建产物）
src/EasySnipLite/bin/Debug/net10.0-windows/win-x64/EasySnipLite.exe

# 测试
dotnet test EasySnipLite.slnx
```

**使用**：启动后常驻托盘。任意应用按下 `Ctrl + 双击空格` → 拖拽框选区域 → `Enter` 确认 → 打开标注编辑器：工具条选择工具（矩形/椭圆/箭头/画笔/荧光笔/马赛克/文字/表情，数字键 1-9 快速切换）、颜色与线宽，`Ctrl+Z`/`Ctrl+Y` 撤销重做，`Delete` 删除选中对象，`Ctrl+C` 复制 / `Ctrl+S` 保存，`Enter` 完成（复制并关闭），`Esc` 关闭不保留。托盘右键菜单可再次唤起区域截图或退出。

## 📦 技术栈

- C# 14 / WPF / .NET 10（`net10.0-windows`），PerMonitorV2 高 DPI 感知
- 零第三方运行时依赖（框架内置 + Win32 P/Invoke）
- 多显示器支持（每显示器独立捕获与遮罩窗口，物理像素坐标统一换算）
- 发布目标：单文件绿色版 exe（`PublishSingleFile` + self-contained）
