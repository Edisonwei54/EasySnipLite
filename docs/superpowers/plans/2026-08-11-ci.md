# CI 自动编译测试 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 EasySnipLite 添加 GitHub Actions CI——PR / push(main) 时自动 build + 跑全部单测，README 显示状态徽章。

**Architecture:** 单个 `.github/workflows/ci.yml`（单 job：restore → build → test → 上传 TRX）；`global.json` 锁定 SDK band（本地 10.0.302 精确命中、CI 滚动到最新）；README badge 指向 workflow 状态。

**Tech Stack:** GitHub Actions（windows-latest / checkout@v4 / setup-dotnet@v4 / upload-artifact@v4）、.NET 10 SDK、xUnit。

## Global Constraints

- 主程序与单测均为 `net10.0-windows`（WPF）→ runner 必须 `windows-latest`，不得用矩阵。
- 本地 SDK 为 10.0.302；`global.json` 必须本地精确命中（不改本地构建行为）。
- 不跑 `dotnet publish` 冒烟 / E2E（runner 无交互桌面）。
- 提交信息带 `Co-Authored-By: Claude <noreply@anthropic.com>`。
- 合并动作禁止执行（规则 9）：push + 开 PR 后停下，由用户手动合并；远程分支不删除。
- 文档同步（规则 10）：README / PROGRESS / CLAUDE.md 在本计划内一并更新。

### Task 1: 创建 CI workflow

**Files:**
- Create: `.github/workflows/ci.yml`

**Interfaces:**
- Consumes: 仓库根的 `EasySnipLite.slnx`（解决方案，含 src + tests 两项目）
- Produces: workflow `CI`（job `build-test`）——GitHub Actions 发现后自动在 PR / push(main) 触发

- [ ] **Step 1: 创建 `.github/workflows/ci.yml`**

```yaml
name: CI

on:
  pull_request:
  push:
    branches:
      - main

jobs:
  build-test:
    runs-on: windows-latest
    steps:
      - uses: actions/checkout@v4

      - name: Setup .NET
        uses: actions/setup-dotnet@v4
        with:
          dotnet-version: 10.0.x
          cache: true
          cache-dependency-path: "**/*.csproj"

      - name: Restore dependencies
        run: dotnet restore EasySnipLite.slnx

      - name: Build
        run: dotnet build EasySnipLite.slnx -c Release --no-restore

      - name: Test
        run: dotnet test EasySnipLite.slnx -c Release --no-build --logger "trx;LogFileName=test-results.trx" --results-directory TestResults

      - name: Upload test results
        uses: actions/upload-artifact@v4
        if: always()
        with:
          name: test-results
          path: TestResults
```

- [ ] **Step 2: 本地校验 YAML 语法**

```bash
python -c "import yaml; yaml.safe_load(open('.github/workflows/ci.yml', encoding='utf-8')); print('YAML OK')"
```

预期：输出 `YAML OK`。若报 `ModuleNotFoundError: No module named 'yaml'`（本机无 PyYAML），则改用手工核对：所有步骤缩进 6 空格、`on:`/`jobs:`/`build-test:`/`steps:` 逐级对齐，语法最终以 GitHub PR 校验为准（Task 3）。

- [ ] **Step 3: 提交**

```bash
git add .github/workflows/ci.yml
git commit -m "ci: GitHub Actions workflow(PR/push main 自动 build+test,TRX 上传)

Co-Authored-By: Claude <noreply@anthropic.com>"
```
